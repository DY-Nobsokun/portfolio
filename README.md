# Nobsokun — Creative portfolio

A responsive portfolio inspired by the supplied landing-page reference, built with HTML, CSS, JavaScript, and Vite.

## Development

Requires Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to any static web host.

## Personalize

- Update the name, introduction, project cards, and contact details in `index.html`.
- Replace the AI-generated placeholder portrait in `public/images/` with your own photograph.
- The four artwork tiles are original CSS preview concepts, not finished client projects. Replace them with your posters, videos, animation, and UX/UI work.
- Contact currently shows a placeholder dialog. Add your real email or social URL before publishing.
- Fonts: DM Sans and Instrument Serif bundled locally from Google Fonts, with system fallbacks.
- The portrait is AI-generated; replace it with your own photo before publishing.

Category filters, project dialogs, the Explore menu, section navigation, and reduced-motion support work without additional dependencies.
